# Waraqa — ورقة

A polished Arabic notes app for Linux, built with Flutter.

Waraqa (Arabic for "a sheet of paper") offers a first-class Arabic
right-to-left interface alongside an English left-to-right one. On first
launch you choose a language; the choice is saved locally with your notes in
`~/Documents/waraqa`.

![Waraqa logo](assets/icon/warqa-ui-fit-lockup.png)

## Features

- Arabic (RTL) and English (LTR) interfaces
- Rich text editing: text colors, lists, quotes, code blocks and more
- Notes stored locally on your machine, optionally PIN-protected
- Paper colors and a distraction-free writing view
